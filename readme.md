# Login Page Using CSS Flexbox

## Description
This project is a simple login page created using HTML and CSS.
It uses Flexbox to arrange the image section and login form side by side.

## Technologies Used
- HTML
- CSS
- CSS Flexbox

## Features
- Split layout with left and right sections
- Image centered using Flexbox
- Login form with email and password inputs
- Login button with hover effect
- Content centered using Flexbox
- Container height set to 100vh
- Responsive layout for small screens

## Files
- index.html - Contains the HTML structure.
- index.css - Contains the CSS styling.
- README.md - Contains project information.

## How to Run
1. Keep index.html and index.css in the same folder.
2. Open index.html in a web browser.
3. The login page will appear.
